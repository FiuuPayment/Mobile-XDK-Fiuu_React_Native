# [Mobile XDK] – Fiuu React Native SDK

<img src="https://user-images.githubusercontent.com/38641542/74424311-a9d64000-4e8c-11ea-8d80-d811cfe66972.jpg">

Fiuu React Native payment module. Install it from npm:

```sh
npm install fiuu-mobile-xdk-reactnative --save
```

The XDK library source is not published in this repository. Use the npm package in your app.

An example application (`FiuuReactExampleProject`) is provided as an integration reference. It depends on the published npm package.

## Recommended configurations

- Node.js Version: 22.13 ++
- Minimum Android SDK Version: 26 ++
- Minimum Android API level: 19 ++
- Minimum Android target version: Android 11 ++
- Minimum React Native version: 0.76 ++
- Example app React Native version: 0.87
- Xcode version: 15 ++
- Minimum target version: iOS 16

## Installation Guidance

**Merchant integration (Android + iOS):** see [MERCHANT_GUIDE.md](./MERCHANT_GUIDE.md) for install, native setup, `startFiuu`, Google Pay, Apple Pay, callbacks, and checksum.

[Wiki installation notes](https://github.com/FiuuPayment/Mobile-XDK-Fiuu_React_Native/wiki/Installation-Guide)

## Example

```sh
cd FiuuReactExampleProject
npm install
```

See [FiuuReactExampleProject/README.md](FiuuReactExampleProject/README.md) for Android, iOS, Google Pay, and Apple Pay setup.
